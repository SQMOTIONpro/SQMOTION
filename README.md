SQMOTION — Professional Motion Graphics Editor

Project Overview

Build a professional Android Motion Graphics and Video Editing application named SQMOTION. The application should provide an editing experience inspired by Alight Motion, while maintaining its own unique identity, architecture, interface, and open-source codebase.

The goal is to create a powerful, modern, feature-rich editing application that gives users complete creative control over video, animation, graphics, and visual effects.

1. Platform & Technology

- Platform: Android.
- Primary programming language: Kotlin.
- UI: Modern, responsive, professional interface.
- Architecture: Modular and maintainable.
- Performance: Optimized for mobile devices.
- Support multiple screen sizes and orientations.
- Open-source architecture with well-documented code.

2. Main Interface

Create a futuristic, professional dark-themed interface.

Design requirements:

- Elegant dark background.
- Neon green as the primary accent color.
- Smooth transitions and animations.
- Modern icons and controls.
- Minimal, clean layout.
- Professional typography.
- No unnecessary buttons or clutter.

Main sections:

- Projects.
- Create New Project.
- Recent Projects.
- Templates.
- Settings.
- Asset Library.

- Layer duplication.

- Blur.

- Masks and paths.

- Automatic interpolation.
- Bezier curves.
- Custom easing.
- Graph editor.
- Motion path visualization.

- Gaussian Blur.

11. Open Source Requirements

The application must be genuinely open source.

Requirements:

- Provide complete source code.
- Use a suitable OSI-approved open-source license.
- Keep modules independent and maintainable.
- Document important classes and APIs.
- Allow developers to add custom effects.
- Allow developers to create extensions.
- Avoid proprietary dependencies wherever possible.
- Do not use Alight Motion's copyrighted code, assets, branding, or proprietary resources.

14. Development Instructions

Build the application in independent development stages:

1. Create the project architecture.
2. Build the main interface.
3. Implement project management.
4. Build the timeline engine.
5. Implement the rendering engine.
6. Implement keyframe animation.
7. Build the effects engine.
8. Implement text and shape editors.
9. Add audio and media support.
10. Implement export functionality.
11. Optimize performance.
12. Test all features.

Do not create fake buttons or non-functional features.

Do not replace complex features with static demonstrations.

If a feature requires a dedicated rendering engine, implement the actual underlying functionality rather than simulating its appearance.

Deliver a complete, buildable Android Studio/Kotlin project with organized source files, dependencies, and setup instructions.

Final Vision

SQMOTION should become a serious open-source Motion Graphics editor for Android, offering a professional editing experience inspired by Alight Motion, with its own identity, advanced animation tools, powerful timeline, flexible effects system, and complete creative freedom.
